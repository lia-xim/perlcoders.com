Section · historical reference

Old links have to land somewhere honest.

These entries record software formerly distributed by the original PerlCoders company. They exist because archived indexes and inbound links still point at the old catalogue URLs — not because there is anything to obtain.

What the Archive is not

Not a catalogue Nothing here is for sale, for download or for support. We are not the former company and did not acquire its software, its customers or its obligations.
Not a redistribution No source code, binary, screenshot or manual is reproduced. Each entry carries only the product name, its historical URLs and a neutral description.
Not a safety judgement Absence of a recorded advisory is not evidence that code was safe. Unmaintained 1990s CGI should be treated as unsafe by default, and every entry says so.

How legacy URLs resolve.

The old catalogue addressed everything through a query string. Each known ?script= value maps to exactly one Archive entry. An unrecognised value returns 404 — never the homepage, because a soft redirect to the front page tells a visitor their link worked when it did not.

Known value
301 → the matching Archive entry
No script= parameter
301 → this page
Unknown value
404 → with an Archive lookup on the error page
Executable CGI, orders, accounts, downloads
410 Gone → permanently, with the reason stated

Reviewed decisions live in config/legacy-url-actions.json. Automated recovery QA checks the matching API responses, built targets and the absence of a catch-all homepage redirect.
