Cookies and storage

No cookies. Two storage keys, both yours.

Short enough to read, specific enough to verify in your browser's developer tools.

Cookies

This site sets no cookies. Not for analytics, not for advertising, not for session handling — there are no sessions, because there are no accounts. You will not see a consent banner here, because there is nothing to consent to.

You can verify this: open your browser's developer tools, go to the storage panel, and look at the cookie list for this domain. It is empty.

Local storage

Two interface preferences are stored in your browser so the site behaves consistently between visits. They never leave your device and are not readable by us.

Keys written by this site

localStorage
Local storage keys, what they hold and why.
KeyHoldsWhy
pc-deck-position A slide index. So a long presentation view resumes where you left it. Written only on pages that have one.
pc-timeline-view A view preference. Legacy key from an earlier Timeline that offered two layouts. The Timeline is now a single vertical chronology and no longer writes it; you can delete it safely.

Clearing site data in your browser removes both. Nothing breaks — the pages simply start from their defaults.

What the Labs tools store

Nothing. The Legacy URL Mapper does not write to local storage at all. URLs you paste exist only in the page you are looking at and are gone when you close the tab. The module ships unminified so you can confirm there is no localStorage call in it.

Third parties

The site links to GitHub for source review and corrections, but does not embed GitHub or run GitHub code. Following an external GitHub link leaves this site; GitHub's own cookie and privacy policies then apply.

Nothing else on this site reaches a third party. Typefaces and the scroll library are both served from this domain — see the privacy policy. A page loading this site makes no request that leaves this origin.
