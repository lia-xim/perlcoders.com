Cookies and storage

No cookies. No browser storage.

Short enough to read, specific enough to verify in your browser's developer tools.

Cookies

This site sets no cookies. Not for Umami audience measurement, advertising or session handling — there are no sessions, because there are no accounts. You will not see a cookie-consent banner here because the analytics setup does not use cookies. The processing and its legal basis are described in the privacy policy.

You can verify this: open your browser's developer tools, go to the storage panel, and look at the cookie list for this domain. It is empty.

Browser storage

The current build does not write to localStorage, sessionStorage or IndexedDB. Interface state lasts only for the open page and is discarded when the page closes. This statement describes the code that is deployed now; if storage is introduced later, this page will name the exact key, purpose and retention behaviour before that release ships.

What the Labs tools store

Nothing. The Legacy URL Mapper does not write to local storage at all. URLs you paste exist only in the page you are looking at and are gone when you close the tab. The module ships unminified so you can confirm there is no localStorage call in it.

Third parties

The site links to GitHub for source review and corrections, but does not embed GitHub or run GitHub code. Following an external GitHub link leaves this site; GitHub's own cookie and privacy policies then apply.

The Umami script and its measurement requests use analytics.contextter.com. The tracker receives page-view data and the bounded events described in the privacy policy; it does not set a cookie or write browser storage. Typefaces and the scroll library remain served from this domain.
