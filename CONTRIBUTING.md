# Contributing

PerlCoders welcomes specific, sourced corrections and narrow implementation fixes.

For editorial corrections, include:

- the affected page and exact claim;
- what is wrong or incomplete;
- a primary source where one exists;
- proposed wording;
- whether you want public credit.

For code changes, keep the patch focused, run `corepack pnpm verify`, and describe any browser testing performed. Do not submit historical binaries, personal data, credentials, generated backlink content, or material you do not have the right to publish.

Participation is governed by the public [Code of Conduct](https://perlcoders.com/code-of-conduct/).
